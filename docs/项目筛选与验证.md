## 本地修改

- Windows 原生 PySide6 界面、EXE 入口、任务日志及停止进程树、账号 DPAPI 加密。
- 讲座：新版 `/sepCard/card` 工作台识别，Edge 启动，复用每个账号的浏览器会话；只确认目标讲座行的报名结果，避免误用其他行的“已报名”；点击前按目标标题重新定位，避免刷新后的行号误选；拒绝把“未成功”判为成功。
- 慕课：从硬编码账号/路径改为独立浏览器手工登录；复制的视频/PDF 处理函数保留来源；超时和服务器未确认抛出错误；执行结束列出剩余任务，Quiz/考试明确不包含。
- 签到：不同任务对同一排课去重；未知结果不重放；截止时间后停止；学校时间校准失败不提交。
- 选课：Selenium 升级到 4.49.0，修复旧 Edge 驱动下载地址失效；本地 WebDriver 请求跳过环境代理。
- 规划：Python 3.10 兼容组合已实测；界面改为两栏以适应统一窗口；源课表和用户数据库分离。
