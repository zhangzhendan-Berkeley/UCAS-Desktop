# 教师与课程评估助手（0.5.5-rc.1）

适用于研究生选课系统 `https://xkcts.ucas.ac.cn:8443`，自动填写你保存的答案，辅助连续处理问卷。无需安装油猴或浏览器扩展；使用应用已有的讲座/SEP 浏览器组件。

## 使用

1. 在“个人信息”保存 SEP 账号。如果尚未启用讲座组件，先到“设置与更新 → 检查并修复功能组件”。
2. 左侧打开“教师与课程评估”，点击“打开教师评估”或“打开课程评估”。程序从学校菜单发现学期入口，不固定学期编号。如 SEP 要求验证，在浏览器完成。
3. 在学校列表选择一个“评估”项目。首次按自己的实际体验填写评分、多选题和主观题，点击浏览器左下角助手的“记住本页答案”。课程、教师两种问卷分别保存。
4. 后续打开同类问卷，助手自动填入题目、选项完全匹配的空白项。已经填写的内容不会覆盖；模板不匹配的题目留空，面板提示数量。可以逐题修改，再次“记住本页答案”即可更新对应模板。
5. 核对当前课程/教师的答案，手动输入验证码，用**学校页面的保存按钮**完成提交。助手不自动点击提交，也不把窗口关闭当作评价成功。
6. 可勾选“返回列表后自动打开本页下一个待评估项目”。只打开文字为“评估”的入口，不自动改动旧评价。本页无待评项目时停留；如有下一页或其他学期，请自行切换。
7. 关闭全部评教窗口结束任务；也可在“任务与日志”停止。运行评教时暂停组件修复入口，避免替换正在使用的依赖。

评教是主动交互任务，因此登录后会显示浏览器。它不会随概览刷新、讲座轮询或启动应用自动运行。其他后台任务不因打开评教而停止。

## 本地数据

答案和独立浏览器会话保存在 `data/evaluation/<账号哈希>/`。模板可能包含你的个人意见，不要公开该目录。SEP 密码继续使用个人信息页的安全存储，不写入模板。验证码不保存。不同账号互不共用模板，不会覆盖讲座任务的会话文件。

## 核验与限制

2026-10-01 在当前账号做了只读核验：2026 秋季教师、课程列表以及两种问卷可访问；主要字段结构与参考项目一致。教师列表当时本页有 12 个“评估”入口，课程列表本页为 0；这只是当时状态，不代表所有课程都评完或其他学期为空。

问卷副本在完全拦截网络的浏览器中验证：课程 29 组、教师 23 组答案均可保存和恢复。额外检查了空 value 多选项、题目变化、保留已有编辑、不同类型隔离、官方域名限制和不自动提交。Qt 页面与原有调度 UI 回归通过。

**没有提交真实评价来验证保存结果；服务器端提交仍以学校提示和列表状态为准。** 当前候选版本地验证平台为 Windows，Mac/Linux 代码沿用既有跨平台浏览器接口，但本次没有在真实 Mac/Linux 设备验证评教。

参考作者与固定提交见 [THIRD_PARTY.md](../THIRD_PARTY.md)。本科 `bkkcpj` 工具不适用于本模块。上游固定最高分/固定评语未作为默认答案使用。
