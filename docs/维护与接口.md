# 维护、更新与扩展

## 工程结构

```text
UCAS-Desktop/
├── UCAS桌面助手.exe           Windows 入口（C# 引导程序）
├── app.py                    PySide6 应用入口
├── ucasdesk/
│   ├── ui.py                 原生桌面界面
│   ├── core.py               路径、DPAPI、数据库、更新检查、Connector 协议
│   ├── iclass.py             轻新课堂接口适配器
│   ├── jobs.py               子进程任务生命周期与日志
│   └── api.py                只读 HTTP API v1
├── adapters/                 各平台任务入口；JSON 从 stdin 传入
├── modules.json              模块 ID、来源、固定 SHA、能力范围
├── vendor/                   上游源码，保留 Git 信息
├── mobile/                   手机只读任务面板
├── tests/                    本地测试及浏览器连通性检查
├── data/                     账号、浏览器会话、任务、个人课表
├── logs/                     运行日志
└── docs/                     来源、验证、补丁、使用说明
```

界面和适配器分离。新增平台时不应修改既有平台的认证实现；新增适配器并在 `modules.json` 登记 `id/source/commit/api_version/capabilities`，再接入 UI。

## Connector API v1（Python 内部接口）

定义位于 `ucasdesk/core.py`：

```python
class Connector(Protocol):
    api_version: int
    def health(self) -> dict: ...
    def execute(self, action: str, payload: dict) -> dict: ...
```

当前 `IClass.execute` 支持 `query`（`date: yyyyMMdd`）和 `sign`（`course_id: 7位数字`）。账号通过构造参数提供，认证会话只存在连接器内存中。学校 JSON 结构异常、时间校准失败和登录失败均抛出可处理异常。

## 子进程任务接口

`Jobs.start(module, title, program, args, payload)` 将 JSON 写入子进程标准输入，避免把账号放在命令行。任务可输出 UTF-8 文本或 JSON 行；父进程按完整行脱敏后写入日志。

退出码约定：`0` 表示程序正常完成本轮；`1` 表示失败；慕课 `2` 表示仍有未完成项；选课 `3` 表示限流类停止。学校操作是否成功，仍由连接器解析服务器返回，并在日志明确记录。

任务状态：`running / stopping / completed / failed / stopped / interrupted`。从托盘明确退出时停止其任务进程树（关闭窗口只隐藏）；重启后历史运行中任务标为 `interrupted`。启用的后台计划会重新检查当天课表/下个讲座时点；已提交或结果不明的操作由持久化记录阻止重放。普通手动任务不自动恢复。

## HTTP API v1

默认 `127.0.0.1:8765`，应用退出时关闭。可在设置启用局域网只读访问。

| 方法 | 路径 | 鉴权 | 返回 |
|---|---|---|---|
| GET | `/v1/health` | 无 | 应用版本、API 版本 |
| GET | `/v1/modules` | Bearer Token | 模块来源、SHA、能力 |
| GET | `/v1/jobs` | Bearer Token | 最近 200 项任务元数据，不含账号、日志路径或日志正文 |
| GET | `/mobile/` | 页面公开；数据接口要求 Token | 手机状态页 |
| POST | 任意路径 | 不支持 | HTTP 405 |

Token 位于 `data/api-token.txt`。示例在本机 PowerShell 执行：

```powershell
$token = (Get-Content .\data\api-token.txt -Raw).Trim()
Invoke-RestMethod http://127.0.0.1:8765/v1/jobs -Headers @{Authorization="Bearer $token"}
```

目前不通过手机 API 接受签到 / 报名写请求。将来增加写接口时需要新增明确的操作模式、参数校验、目标去重、结果不明时的停止机制和兼容版本号。

## 更新流程

1. UI 检查固定 GitHub 来源的 HEAD，对比 `modules.json` 所指本地仓库 HEAD。
2. 新提交通过 Git fetch 精确 SHA 下载到 `updates/<module>/<sha>`，并核验实际 HEAD；当前目录不被替换。
3. 在暂存目录查看接口、依赖和页面选择器变化。上游更新后的补丁重放参考 `patches/lecture-local.patch`；慕课抽取的本地函数来源和变更见 `THIRD_PARTY.md`。
4. 在新的工作副本安装锁文件依赖，执行下述检查；再用自己的账号进行只读验证，然后验证目标写操作。
5. 停止运行任务，保留旧目录作为回滚副本，切换上游代码并更新 `modules.json`。不要覆盖 `data/`、`logs/` 或运行环境。

不提供“自动覆盖全部源码并执行”的按钮：本次对上游有 Windows 适配和结果判断修复，直接 `git pull` 不能保证这些改动仍兼容。

## 运行环境与复现

本机环境：Python 3.10.19；PySide6 6.10.1；Node.js 24.21.0；Selenium 4.49.0。精确依赖快照见 `requirements.txt`。

规划器上游元数据要求 Python 3.12 及较新的 pandas/PySide6/reportlab。本地没有强行安装它的包元数据，而是以源码模块方式载入，并使用本机兼容版本验证了导入、GUI、冲突检测、CSV/Excel/JSON/PDF 导出。此兼容组合已记录，升级时需重新验证。

Selenium 4.27.1 自带的旧驱动下载地址在本机失败，已在独立虚拟环境升级到 4.49.0；子进程对 `localhost/127.0.0.1/::1` 设置 `NO_PROXY`，避免系统代理导致 WebDriver 本地连接出现 Bad Gateway。

```powershell
# 从 UCAS-Desktop 目录执行
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe tests\ui_smoke.py
npm.cmd --prefix vendor/ucas-humanity-lecture-bot run build
npm.cmd --prefix vendor/ucas-humanity-lecture-bot test
node tests/browser_health.mjs
```

`tests/ui_smoke.py` 使用离屏界面做测试并生成预览图；先从托盘菜单退出正常应用再运行。`tests/tray_smoke.py` 在真实 Windows 托盘中使用隔离的临时数据及独立 API 端口，验证关闭/最小化后任务继续、托盘及跨进程唤醒、显式退出停止任务。

窗口关闭只隐藏；任务生命周期由托盘中的“退出程序（停止自动任务）”管理。托盘不可用时回退到关闭退出。`ucasdesk/instance.py` 使用当前数据目录对应的用户本地 IPC，让再次启动快捷方式恢复已有窗口；`app.lock` 仍负责防止重复进程运行任务。

图标源文件是 `assets/app.svg`，运行 `.venv\Scripts\python.exe build\make_icon.py` 生成 PNG 与多尺寸 ICO。原生 Windows 启动器源码在 `build/Launcher.cs`，可以使用系统 .NET Framework 的 `csc.exe` 重新编译，并传入 `/win32icon:assets\app.ico` 嵌入图标。

## 数据备份与搬迁

备份个人设置时保留 `data/`。DPAPI 账号文件绑定当前 Windows 用户，搬到其他账户不能保证解密；届时重新登录即可。浏览器目录含会话，不应公开上传。

公开版通过 `scripts/setup.py` 创建独立虚拟环境，使用系统 Node.js；不依赖开发者的相邻项目。迁移到其他机器时按 README 重新安装，不能只复制 `.exe`。


## 后台日历计划与观测记录

- `ucasdesk/automation.py`：GUI 内每 5 秒检查本地墙上时钟；每日 08:00 和每小时 01/31 分触发独立适配器，所有网络工作都在子进程。`automation.json` 保存启用状态和筛选，不保存密码。每日计划在应用重启后重查今天；讲座时点持久化去重、宽限 2 分钟，不补发历史轮次。
- `adapters/iclass_worker.py` 的 `mode=daily`：仅查本人的当天课表，去掉已结束/已签到/重复排课；复用原定时执行逻辑。`iclass.daily-plan` 事件包含日期与课程，供界面显示。
- `ucasdesk/sign_ledger.py`：SQLite `BEGIN IMMEDIATE` 在提交前原子占用 `(账号SHA256, 排课ID)`；成功和未知结果不重放；仅明确可重试结果允许 120 秒后重试，累计最多 3 次。任何外部写操作适配器都应保留同等的未知结果保护。
- `adapters/lecture_observe.mjs` / `lecture_history.mjs`：先只读观察、持久化，再按勾选状态报名。观察身份由名称、时间、地点生成，不使用会受报名按钮文字影响的上游 ID。基线不作新增，所有校区保留记录，仅雁栖湖参与时点分布。JSON schema `version=1`；Markdown 报告每轮更新。
- `patches/lecture-campus.patch` / `lecture-campus.ts`：地点从表头对应字段提取，报名候选仅限雁栖湖，实际点击前重新检查；所有旧报名入口同样生效。新环境安装和旧环境升级均通过 `prepare_lecture()` 应用并重编译。
- 测试：`python -m unittest discover -s tests -v`，`node --test tests/lecture_history.test.mjs`，安装外部模块后运行 `node tests/lecture_campus_smoke.mjs`。浏览器测试完全拦截外部网络，用本地 HTML 验证非目标校区不会点击报名。


## 共享账号与已选状态

- `Vault.set()` 默认 DPAPI 持久化，先完成加密写盘再更新内存；未来模块继续通过 `Vault.get("sep" / "iclass")` 读取，不另存密码。
- `ucasdesk/sep.py` 提供共用登录与已选表解析；`adapters/account_worker.py` 检测密码时使用全新浏览器、同步课程时使用按账号隔离的浏览器，输出 `account.check` / `account.courses` JSON 事件。`selection_worker.py` 使用同一登录函数与按账号隔离的浏览器目录。
- `IClass.my_courses()` 仅查询本人的课程，起止日期确定学期；观察到接口 semesterName 可能保留旧年份。不要用该字段直接覆盖规划学期。
- `ucasdesk/enrollment.py` 管理 `data/planner/enrollment.json` 快照，按账号 SHA256 隔离有效性；`ucasdesk/planner.py` 继承上游窗口，保持原有冲突/导出行为并添加已选状态与抢课勾选。勾选持久化在 `grab-courses.json`，与是否已选上分开。
- 新数据仅完整编码与名称唯一匹配才自动加入本地库对应的课表；查到课程不等于证明教务审核通过。用户修改账号或查询未完成时不误用旧身份结果。
- 测试入口：`tests/test_enrollment.py`、`tests/profile_planner_smoke.py`。个人信息与规划截图全部使用虚构课程/账号。
