# Windows 便携版

## 普通用户：解压后直接运行

1. 下载 `UCAS-Desktop-0.2.0-Windows-x64.zip`，右键“全部解压”到自己有写入权限的文件夹，如桌面或 D 盘。
2. 打开解压后的文件夹，双击 **UCAS桌面助手.exe**。不要在压缩软件内直接运行，也不要只复制 EXE；它需要同目录的资源和运行环境。
3. 到“个人信息”填写自己的 SEP 和轻新课堂账号，保存后即可使用。
4. 需要人文讲座预约或自动选课时，进入“设置与更新”，点击 **一键启用讲座预约与抢课**。等待“任务与日志”显示完成，再返回对应功能；首次需要能访问 GitHub。这个过程只准备组件，不会登录学校或提交任务。

**不需要安装 Python、Node.js、Git、pip，也不需要管理员权限或修改环境变量。**

适用 Windows 10/11 x64。浏览器任务使用系统 Microsoft Edge；首次使用 SEP 浏览器任务时，Selenium 会自动下载与 Edge 对应的驱动，需要联网。学校功能本身也需要网络连接。

关闭窗口会隐藏到托盘，后台任务继续运行；右键托盘“退出”会停止程序与任务。电脑关机、睡眠或完全退出后不会继续执行。

## 数据与升级

- 首次运行时在本目录生成 `data/`、`logs/`。发行包不包含任何个人账号、课程选择、登录 Cookie 或历史任务。
- 密码由 Windows DPAPI 加密。便携指程序无需安装，不代表加密账号可以在其他电脑或其他 Windows 用户之间通用；换电脑请重新输入账号。
- 升级前从托盘退出。解压新版到另一个文件夹，**备份后**将旧版 `data/` 整个复制到新版中（同一电脑、同一 Windows 用户）。不要直接删除旧版。外部组件在新版中按需一键启用。
- App 内的课程库使用相对路径保存，旧版 `data/planner/` 路径会迁移到新目录。若自行选择了 App 文件夹外的数据库，也要保留那个文件。
- 首次启动失败时双击 `启动诊断.cmd`，查看窗口错误与 `logs/startup-error.log`。反馈日志前请检查是否含个人信息。

## 包内内容与许可

- `runtime/python/`：官方 CPython 3.12.10 Windows 嵌入式发行版与依赖；采用该版本以兼容已固定的 OCR / 数值库版本，它不是 Python 最新安全版本。
- `runtime/node/`：Node.js 24.21.0 x64 与 npm。
- `assets/`、`mobile/`、`ucasdesk/`、`adapters/`：界面、图标、手机面板及应用源码。
- `vendor/UCAS-Course-Selector/`：保留 MIT LICENSE 的规划器与原始公开课表。
- `vendor/mooc-english/`：保留来源、package.json 中 ISC 标记及公开源码的慕课依赖。
- 讲座与选课上游没有明确独立 LICENSE，不将它们的完整源码放进公开 ZIP。用户点击启用时从原仓库下载固定提交，校验 SHA256，再应用本项目补丁。依赖的通用 Node 包已经准备好。
- Python、Node、Qt/PySide6 和其他依赖的许可随各目录保留；Python 依赖下载地址、版本与校验信息在 `runtime/python-dependencies.json`，模块来源在 `modules.json` / `THIRD_PARTY.md`。Qt/PySide6 使用动态库，应用源码随包提供，用户可以按原许可证替换或调试这些组件；对应开源源码可从 [Qt](https://download.qt.io/archive/qt/) 与 [Qt for Python](https://download.qt.io/official_releases/QtForPython/) 获取。

## 维护者构建

在源码仓库的 Windows 构建机安装 Python 和 `requests` 后运行：

```powershell
python scripts/build_portable.py --version 0.2.0
```

构建脚本从固定来源下载并校验独立运行时，安装所需 Python 包，从固定提交读取上游公开源码，生成启动器与 ZIP / SHA256。缓存位于 `data/portable-cache/`，输出位于 `dist/`；已有输出目录不会被覆盖。用户不需要执行这个步骤。

源码仓库默认忽略 `dist/`；成品压缩包应作为 GitHub Release 附件发布。
