# v0.5.5

正式版，基于 v0.5.4，包含教师与课程评估助手和实验性公开课表守课功能。

- 新增教师与课程评估助手：读取当前学期列表，支持用户手动验证码和最终提交。
- 新增公开课表守课：不登录查询公开课程人数，保存有效基线，查询失败不误判为零；人数下降信号合并后才可触发个人选课核验。
- 公开守课默认关闭；可选择仅监控，或触发后进入现有选课执行器。结果不明会暂停该课程，不自动重提。
- 讲座和选课任务继续使用原有账号隔离、任务互斥和会话恢复逻辑。

## 未验证范围

当前选课系统未开放，公开守课、选课登录恢复和真实提交没有用学校账号完成端到端验证。公开人数包含不同学生类别，不代表本人具有名额或资格。启用前请确认学期 `termId`，运行后务必核对 SEP 预选列表；建议先使用“仅监控”。

教师与课程评估的真实问卷提交同样需要用户在浏览器中完成验证码并确认，未承诺自动提交成功。

## 更新方式

退出旧版托盘程序，下载对应平台的 v0.5.5 包；源码用户重新运行安装器。账号、任务配置、课表和日历数据保留，但更新后应重新检查组件并逐项验证。
