# v0.5.5-rc.1 · 教师与课程评估助手

公开候选版，基于 v0.5.4；稳定版仍为 v0.5.4。提供 Windows x64、Mac Apple Silicon / Intel 便携包及源码。

从旧版更新：退出托盘程序，解压新版到新目录，使用“迁移旧版数据.cmd”（Mac 使用包内迁移工具）保留账号和配置。教师与课程评估依赖现有讲座组件，首次使用可在“设置与更新”检查并修复功能组件。

- 新增左侧“教师与课程评估”，共用个人信息页的 SEP 账号，从学校菜单发现当前学期。
- 记住用户自行填写的答案，在后续同类问卷自动填写匹配的空白题。课程和教师模板、不同账号相互隔离。
- 支持返回列表后自动打开本页下一个待评估项目；验证码与学校最终保存由用户操作，不自动修改已有评价。
- 适配实际页面中多个选项的 value 均为空的情况，使用完整题目及有序选项签名匹配。
- 修正概览“今天全部讲座”入口，继续指向已合并的讲座页，避免新侧栏导致跳转错位。

验证：Windows 上 102 个 Python 测试（1 项平台跳过）、自动调度/概览/讲座 Qt 回归、拦截网络的评教浏览器测试通过。当前学校列表与问卷做只读核验；问卷离线副本恢复了课程 29 组、教师 23 组测试答案。真实提交和 Mac/Linux 评教尚未验证。

详见[操作说明](../教师与课程评估.md)和[参考作者](../../THIRD_PARTY.md)。
