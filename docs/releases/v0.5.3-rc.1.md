# v0.5.3-rc.1 · 选课等待与会话恢复候选版

本版采纳 [@shcw0405 的 Issue #2](https://github.com/zhangzhendan-Berkeley/UCAS-Desktop/issues/2) 中范围较小、可独立回归的建议。基于 `v0.5.2-mac.1`，作为候选版验证，不替换现有稳定版安装包。

## 三项改动

1. 定时任务在执行前 5 分钟才开始准备浏览器和登录，避免提前数小时登录后空等。验证码仍由用户处理；若验证耗时较长，执行可能晚于计划时间。
2. 提交前的只读课程查询明确进入登录表单或出现失效提示时，在同一浏览器中恢复登录，并重新核对是否已选、完整课程编码及可选状态。每次检查最多恢复一次，整个任务最多两次。限流、网络故障、陌生页面和错误凭据不会触发无限重登。
3. 仅明确的满员/不可选终止结果允许继续原有轮询。不能因为日志早先出现过“已满”就重试；提交结果不确定时结束该课程的自动处理，要求用户核对预选列表。

课程选择、轮询间隔、轮次上限、验证码与实际提交仍复用原流程。没有新增公开课表监控、后台服务或新的功能模块。

## 验证与边界

- 新增 13 个专项用例：正常会话、查询中失效、恢复后已经选上、网络错误、限流、恢复次数上限、定时等待、只读预览、明确满员轮询及提交未知不重提。
- 真实浏览器离线 DOM 检查登录表单、可见失效提示、隐藏表单、帮助文字和非官方主机；所有学校 HTTP(S) 请求均被拦截。
- 本地 Python 共 96 项测试，1 项跳过；跨平台完整检查以本候选版关联 CI 为准。
- 未进行真实账号的两小时等待或选课提交。Issue 中的“两小时固定过期”是报告者的使用观察，尚未独立确认，代码不硬编码该时长。

## 版本与回退

- 本次仅发布候选源码 ZIP（含 SHA256），不是新的免安装包。普通用户继续使用 README 指向的 Windows v0.5.2 / Mac v0.5.2-mac.1 安装包。
- 开发/测试请使用独立源码目录，按源码安装步骤准备环境，避免覆盖正在运行的安装目录。不要并行运行新旧版本的同一选课任务。
- 标签 `v0.5.3-rc.1` 固定本次代码；稳定基线 `v0.5.2-mac.1` 保留，可随时切回。没有数据结构迁移，也不会自动替换用户的本地程序。
- 人工验收应先运行“仅检查目标课程，不提交”，确认定时等待与验证码处理，再在用户明确选择课程时验证真实系统流程。只有后续验证通过，才提升为正式版并重建安装包。

界面版本号、Windows 默认打包版本以及 Mac 包名/版本字段从应用版本常量读取，避免再次产出名称与源码版本不一致的包。
