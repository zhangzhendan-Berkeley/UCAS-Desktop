# UCAS Desktop v0.5.0

本次为 macOS 优先的源码版本，整合讲座自动化、日历导入、Linux 支持及此前主分支修复。

## 更新

- 人文、科研讲座启用计划后每小时 01 分查询并尝试报名。保留雁栖湖筛选、科研同开始时间单选和 AI 关键词优先；报名受学校状态与现有筛选限制。
- 科研讲座部门为本科部时，不显示、不报名、不导入日历，提交前再次核对。
- macOS 支持未来七天课程与讲座导入；已预约和明确无需报名的讲座可导入，需要报名但未报名的场次不导入。
- 修复“已经预约过”识别、无课日期 STATUS=2 被误报为课表查询失败，以及讲座提醒弹窗跳转。
- 包含今日讲座、有效学时、到场提醒、分页查询、验证码等待、本机 .app 启动器构建及 Linux 源码支持。
- 修复科研讲座模块在全新安装时的配置补丁，并覆盖可选模块安装路径。

## 下载与安装

附件 `UCAS-Desktop-0.5.0-source.zip` 是纯源码包，附 SHA-256 校验文件。不包含个人账号、缓存、日志、Python/Node 运行时或第三方 vendor 模块。

macOS 需要 macOS 13+、Python 3.10–3.12、Node.js 22+、Git 和 Edge/Chrome。在解压后的项目目录执行：

```bash
python3.12 scripts/setup.py --with-external-modules
bash 启动mac.sh
```

可选执行 `python3.12 scripts/build_macos_app.py` 构建绑定本机项目目录的未签名 .app；它不是独立便携应用。本次不提供新版 Windows 便携包，旧版 Windows ZIP 请到 v0.4.0 Release 下载。

## 升级

从菜单栏完全退出旧进程，备份 data/，然后运行 `git pull --ff-only` 并重新执行安装命令。重启后刷新讲座与听讲记录，再导入日历。旧日历事件不会自动删除。自动任务需要应用运行、电脑保持唤醒；两个讲座任务共用会话，忙碌超过时点宽限可能跳过本轮。
