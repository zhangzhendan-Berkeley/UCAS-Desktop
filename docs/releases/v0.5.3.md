# v0.5.3

## 讲座预约

- 学校返回“目前未到讲座预约时间或讲座预约时间已过，无法预约！”时，记录 `outside-window`，继续下一场。该场不会永久加入满员名单，下次轮询仍检查。
- 人文、科研各有“结果不明时暂停后续报名”勾选框，默认关闭。关闭时继续检查其他候选，保留真实未知结果；开启时恢复暂停逻辑。成功提醒和累计次数只采纳确认成功的结果。
- 人文观察任务在开关关闭时不再被旧的 `bookingPending` 阻挡。异常、旧历史和实际报名状态仍保留；开启保护后，未确认的 pending 仍需核对学校记录。
- 分别设置人文、科研检查小时和每小时 01 / 31 分开关，点击“保存自动任务”后生效。关闭某一类计划不会停止另一类。

## 其他已纳入修复

包含 v0.5.3-rc.1 / rc.2 的选课开始前登录准备、提交前会话恢复和讲座时间设置。选课未知提交结果仍不自动重放。保留原有慕课、后台浏览器与 Mac iCloud 日历集成。

## 下载与升级

- Windows：`UCAS-Desktop-0.5.3-Windows-x64.zip`，解压双击 EXE；不需要安装 Python / Node。
- Mac Apple Silicon：`UCAS-Desktop-0.5.3-macOS-arm64.zip`。
- Mac Intel：`UCAS-Desktop-0.5.3-macOS-x64.zip`。
- Windows 从托盘退出后，使用新版“迁移旧版数据.cmd”保留账号和计划。Mac 退出旧版后替换 `.app`，Application Support 和钥匙串中的账号及数据沿用。
- 已安装旧讲座组件的源码用户重新执行安装脚本；便携用户运行“设置与更新 → 检查并修复功能组件”，使新策略补丁实际生效。
- 发行包不含个人账号、Cookie 或真实学校任务记录；附 SHA256 校验文件。

## 验证范围

回归覆盖讲座弹窗分类、连续候选处理、人文/科研保护开关缺省与显式设置、UI 保存、组件重新安装和原有 Python / Node 功能。跨平台 CI 使用 Windows、macOS 与 Linux；Mac 两种芯片在原生运行器构建并验证独立运行环境、迁移后的启动、组件修复和日历助手。

测试使用本地页面和模拟学校反馈，不提交真实报名，不代表学校当前全部页面或真实 iCloud 写入均已验证。Mac 应用仍是临时自签名，未做 Apple Developer ID 公证，首次打开步骤见 [Mac 说明](../macOS便携版说明.md)。
