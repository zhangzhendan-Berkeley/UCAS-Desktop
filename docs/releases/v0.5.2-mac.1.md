# v0.5.2-mac.1 · macOS 独立发行版

- Apple Silicon（arm64）与 Intel（x64）分别原生构建，macOS 13+；内置 Python、Node、Qt、慕课和选课规划依赖，无需 Homebrew/Xcode。
- 将 `.app` 拖到“应用程序”后启动。私有数据独立保存在 `~/Library/Application Support/UCAS Desktop`，账号使用原有 macOS 钥匙串；更换 `.app` 不覆盖配置。
- 课程、已报名人文/科研讲座继续支持同步到 iCloud 的 UCAS 日历；EventKit 组件已预编译，保留地点、更新本应用创建的事件并避免重复。修复明日同步使用错误账号缓存、忽略未来课表缓存及阻塞界面的问题。
- 保留 v0.5.2 的慕课目录兼容、组件检测与修复。首次讲座/选课组件需在设置中从上游固定版本安装。

## 下载与使用

选择 `macOS-arm64.zip` 或 `macOS-x64.zip`（文件名前有版本号），解压后阅读“先读我.md”。`.sha256` 是校验文件。源码 ZIP 面向开发者，不是安装包。

日历：在系统日历的 iCloud 下创建唯一可写的 **UCAS** 日历，刷新课表和讲座后，在概览点击 **同步未来 7 天到 iCloud UCAS**，首次允许日历完全访问。云端与 iPhone 同步由系统日历负责。

包使用 ad-hoc 签名，没有 Apple Developer ID 公证。若被拦截，请确认来源后在“系统设置 → 隐私与安全性”对本应用选择“仍要打开”。

## 验证范围

两种架构独立验证原生 `.app`、迁移路径后的启动、内置运行时、Qt/课表、Keychain、慕课新旧目录、组件安装/损坏修复及原生日历组件的数据处理。真实学校账号、私人 iCloud 授权及跨设备云同步没有在 CI 中测试，不能据此宣称这些流程已端到端验证。

Windows 用户继续使用 [v0.5.2 Windows 便携包](https://github.com/zhangzhendan-Berkeley/UCAS-Desktop/releases/tag/v0.5.2)。本版只新增 Mac 安装包，原作者及贡献者致谢继续保留在 README / THIRD_PARTY.md。
