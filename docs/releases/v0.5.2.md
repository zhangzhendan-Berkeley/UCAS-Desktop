# v0.5.2 — 慕课目录与安装修复

## 修复

- 兼容国科大在线 `posCatalog_select` 新章节目录和旧 `ncells` 目录，以及嵌套页面、新标签页；正确读取任务点和区分测验。新增只读章节诊断和持续状态提示，避免一直无反馈等待。
- 缺少慕课依赖时显示修复入口；重复任务不再争用同一浏览器目录。
- 讲座补丁统一生成，从固定干净版本重建，修复旧目录重复安装和 background.js 缺失。
- 组件完整性与构建版本检查；修复采用暂存、验证、备份、替换，失败保留旧安装。发布与上游源码更新入口明确区分。
- 便携包包含运行时、慕课与课表；讲座/选课上游仍由用户从原仓库按固定提交下载。新增旧版数据迁移入口。

## 下载

- Windows x64：下载 Windows-x64.zip，全解压后运行 EXE，无需本地 Python/Node/Git。
- macOS / Linux：下载 source.zip，按 README 安装运行；没有独立 macOS/Linux 二进制安装包。
- 同名 sha256 文件用于验证下载完整性。

本地回归包含新旧慕课 DOM、嵌套页面、组件损坏/修复/失败回滚、数据迁移及讲座完整补丁构建。实际学校页面只读验证识别到新版目录、视频和 PDF，未代为完成整门课程或测验。Windows 便携包需通过独立运行时、启动、组件修复和安装诊断后发布。跨平台 CI 结果以发布关联的提交为准。
