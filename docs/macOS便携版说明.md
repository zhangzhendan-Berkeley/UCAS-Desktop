# UCAS Desktop · macOS 独立版

## 安装

1. 在“关于本机”查看芯片：Apple M 系列选 `arm64`，Intel 选 `x64`。系统要求 macOS 13 或更新；发布包在 macOS 15 的两种架构分别测试。
2. 解压下载的 ZIP，将 **UCAS Desktop.app** 拖到“应用程序”，双击打开。无需 Python、Node、Homebrew 或 Xcode。
3. 首次启动会准备本地运行目录，可能需要几十秒。应用使用系统已安装的 Chrome 或 Edge，请先安装其中一个浏览器。
4. 进入“个人信息”填写账号。讲座和选课组件首次使用时，点击“检查并修复功能组件”，从注明来源的上游仓库下载固定版本。

此包只有本地 ad-hoc 签名，没有 Apple Developer ID 公证。若系统阻止打开，在确认下载来自本仓库后，到“系统设置 → 隐私与安全性”对这个应用选择“仍要打开”。无需关闭系统整体安全保护。

## iCloud 日历：课程和讲座

1. 在 macOS“系统设置 → Apple 账户 → iCloud”开启日历同步，并在系统“日历”应用的 **iCloud** 账户下新建一个名为 **UCAS** 的日历（保持唯一且可写）。
2. 在助手概览先“一键刷新全部信息”，再点击 **同步未来 7 天到 iCloud UCAS**。课程从轻新课堂查询未来七天；人文/科研讲座使用最近刷新的缓存，只有已报名或无需报名且符合显示规则的讲座会导入。
3. 首次同步允许 **UCAS Desktop / UCAS Desktop Calendar** 访问日历；macOS 14 及以上需要“完全访问”，以便检查重复事件。
4. 同一标题和开始时间的事件不会重复创建。本应用创建的事件会更新地点和结束时间；不会删除你的其他事件。日历组件已预编译，不需要安装 Swift/Xcode。
5. “今日讲座”保留“立即同步明日到 macOS 日历”；运行期间每日 22:00 会用已有缓存尝试同步明日安排，电脑需保持唤醒。建议先同步未来七天课表、刷新讲座，避免缺少明日缓存。

助手显示成功代表已写入**本机的 iCloud 日历**；同步到 iPhone 的进度由苹果系统控制。没有权限或 iCloud 日历尚未就绪时会保留 ICS 文件，提示中可见保存路径，能够手动导入。

## 数据与升级

- 数据与日志：`~/Library/Application Support/UCAS Desktop/data` 和 `logs`；程序副本：同目录下的 `releases`。账号密码继续存入 macOS 钥匙串，不打包、不上传。
- 从菜单栏托盘完全退出后替换 `.app` 即可升级；不要删除上述数据目录。旧运行副本保留供排查，不会覆盖个人配置。
- 旧源码版账号仍使用相同钥匙串服务。需要搬迁课表、计划等数据时，在退出两个版本后，将旧源码目录 `data` 的内容备份并复制到上述新 `data`，保留浏览器配置；不要从 Windows 复制 DPAPI 密码文件。
- 启动失败日志：`~/Library/Logs/UCAS Desktop/launcher-error.log`，或上述 `logs/startup-error.log`。

## 验证范围

两种架构分别运行包内 Python/Node、实际 `.app` 启动、课表加载、组件安装与损坏修复、慕课目录识别、Keychain 和日历数据转换测试。CI 不登录私人 iCloud，也不会写入真实课程/讲座；真实 Apple 账户授权和设备间云同步需用户首次使用确认。
